# Simulation of Localization

Numerical simulations supporting the master's thesis **“Design of an SDR-based Sensor Array for Monitoring Electromagnetic Interference on the Einstein Telescope Pathfinder”**.

This repository investigates the feasibility and limitations of techniques for identifying and localizing electromagnetic interference (EMI) sources within ETpathfinder. It is intended to grow as additional simulations are developed.

## Current simulation

### Two-antenna AoA: spherical wavefront curvature

**Script:** `etpathfinder_aoa_spherical_sim_refactored.py`

This simulation quantifies the angular bias that results when a **plane-wave angle-of-arrival (AoA) estimator** is applied to the phase difference produced by an **ideal spherical wave**.

The baseline geometry models a two-dimensional, L-shaped installation room with two arms of length 11 m and width 2.8 m. The receivers are at A1 = (0, 0) m and A2 = (0, 2.8) m. Source positions are sampled at the centers of valid grid cells throughout the room.

Default parameters:

| Parameter | Value |
| --- | --- |
| Operating frequency | 14.5 MHz |
| Antenna spacing | 2.8 m |
| Room arms | 11 m each |
| Room width | 2.8 m |
| Grid spacing | 0.1 m |
| Angular-error threshold | 10° |

#### Mathematical model

The main mathematical functions are intentionally separated from grid evaluation and plotting so the calculations can be reviewed independently.

For a candidate source at $S=(x,y)$, the propagation distances are

$$
r_1=\sqrt{x^2+y^2},\qquad r_2=\sqrt{x^2+(y-d)^2}.
$$

The spherical-path phase difference (unwrapped) is

$$
\Delta\phi=\frac{2\pi}{\lambda}(r_1-r_2),\qquad \lambda=\frac{c}{f}.
$$

That phase difference is then deliberately passed through the **plane-wave** estimator:

$$
\hat\theta=\arcsin\left(\frac{\Delta\phi\lambda}{2\pi d}\right).
$$

The true geometric direction, relative to the array midpoint and measured from positive $x$, is

$$
\theta_{\mathrm{true}}=\operatorname{atan2}(y-d/2,x).
$$

The absolute angular error is

$$
\epsilon_\theta=|\hat\theta-\theta_{\mathrm{true}}|.
$$

**Important:** The expression for $\hat\theta$ is *not* a dedicated spherical-wave localization estimator. It is the conventional plane-wave estimator tested against spherical-wave propagation.

In the script, inspect the **`MATH MODEL`** section first:

- `source_to_antenna_distances`
- `spherical_phase_difference`
- `plane_wave_aoa_estimate`
- `true_source_angle`
- `angular_error`

Grid generation and statistics are handled separately by `make_source_grid`, `calculate_error_map`, and `summarize_error_map`. Plotting and exports do not alter the calculated angles.

## Getting started

Requires Python 3 with NumPy and Matplotlib.

```bash
python -m pip install numpy matplotlib
```

Run the baseline simulation:

```bash
python etpathfinder_aoa_spherical_sim_refactored.py --output results/spherical_wavefront
```

To change the resolution or threshold:

```bash
python etpathfinder_aoa_spherical_sim_refactored.py \
  --step 0.05 --threshold 10 \
  --output results/spherical_wavefront
```

On Windows PowerShell, enter the command on one line or use PowerShell's backtick for line continuation instead of `\`.

Run `python etpathfinder_aoa_spherical_sim_refactored.py --help` for all command-line options.

### Generated outputs

The script writes the following to the directory specified by `--output`:

| File | Description |
| --- | --- |
| `aoa_spherical_error_map.png` / `.pdf` | Spatial map of absolute AoA error |
| `aoa_spherical_threshold_map.png` / `.pdf` | Locations exceeding the configured error threshold |
| `aoa_spherical_error_histogram.png` / `.pdf` | Distribution of the evaluated angular errors |
| `aoa_spherical_grid_data.csv` | Per-source-position distances, phase, angles, and errors |
| `aoa_spherical_results.txt` | Summary statistics and simulation parameters |

The outputs can be regenerated by running the script; they need not all be committed to the repository.

## Scope and limitations

The present simulation isolates the effect of **spherical wavefront curvature** under simplifying assumptions:

- Two-dimensional, ideal free-space scalar spherical propagation
- Perfectly synchronized receiving channels and unwrapped phase
- No receiver noise, multipath reflections, conductive structures, or antenna coupling
- A stationary monochromatic source
- Uniform weighting of valid spatial grid-cell centers

The results are therefore **not** a validated prediction of localization accuracy in the real ETpathfinder electromagnetic environment. The reported fraction of grid locations exceeding a threshold is a property of the selected spatial sampling, not the probability of a source occurring there.

The code assumes the source lies in the modeled nonnegative-coordinate region; angle definitions and sign conventions should be preserved when extending the geometry.

## Planned extensions

Future simulations may include:

- AoA sensitivity to phase-measurement uncertainty
- Additional receiving antennas and alternative array geometries
- Time-difference-of-arrival (TDoA) analysis
- Multipath/reflections and more realistic propagation models
- Comparisons with source-identification approaches

These are **planned directions**, not implementations currently present in the repository.

## Reproducibility and contributions

For each new simulation, document its physical assumptions, geometry, mathematical equations, configurable parameters, validation checks, and generated outputs. Keep mathematical calculations distinct from plotting and file-writing code so results remain easy to audit.

This repository is research code developed for a master's thesis. Results should be interpreted in light of the assumptions of each simulation.
